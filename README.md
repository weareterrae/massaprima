# Massa Prima — Website

Site institucional da **Massa Prima** (by Quente e Bom) — matérias-primas de panificação e pastelaria, produzidas em grande parte em Angola.

## Estrutura

- `index.html` — página principal (hero, produtos, receitas, "Feito em Angola", apoio, contactos) com o assistente **Chef Prima**.
- `catalogo.html` — catálogo online com ficha técnica de cada produto (ingredientes, dosagem, modo de aplicação, valores nutricionais, formatos).
- `assets/` — logótipos, fotografia de produto (`produtos/`) e de equipa (`pessoas/`).

Site 100% estático — publicado via **GitHub Pages**.

## Publicação

Servido diretamente da branch `main` (raiz). O ficheiro `.nojekyll` desativa o processamento Jekyll.

> Notas pendentes antes do lançamento público: número de WhatsApp comercial, e-mail e domínio próprio (ex.: massaprima.co.ao). O assistente Chef Prima é, nesta versão, baseado em regras + base de conhecimento local; a ligação a IA fica para a fase seguinte.
